# KrishiSaarthi AI: Screenshots Guide

This folder holds screenshots for your final Kaggle submission page and GitHub repository. Capture and save the images with the exact names below:

---

## Required Screenshots

### 1. `home_ui.png`
- **What to capture**: The main dashboard screen of the Streamlit application upon loading.
- **Highlights**: The NPK soil health widgets, input sliders in the sidebar, and the "Generate Farm Action & Market Plan" primary button.

### 2. `agent_trace.png`
- **What to capture**: The Streamlit interface during execution, displaying the progress box logs:
  - *Weather Agent checking forecast...*
  - *Crop Agent recommending suitability...*
  - *Market Agent querying APMC mandi rates...*

### 3. `final_report.png`
- **What to capture**: The compiled **Weekly Action Plan** tab outputs.
- **Highlights**: The synthesized Monday-to-Sunday action schedule markdown table and the sustainability tips.

### 4. `test_results.png`
- **What to capture**: Your terminal screen showing the successful execution of the test suite.
- **Highlights**: Output of `python -m pytest` with `8 passed in X seconds`.

---

## How to take screenshots:
1. Start the Streamlit app: `streamlit run app.py`
2. Configure settings and click **Generate**.
3. Use your OS snapshot utility (`Win + Shift + S` on Windows) to capture clean, cropped images.
4. Save them in this directory with the exact filenames listed above.
